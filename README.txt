 Parcial Final

Como ejecutar los 2 programas tanto Java y Python junto a la creación de la base de datos 

Base de Datos
Servidor: localhost (127.0.0.1)
Puerto: 3306
Base de Datos: parcial_final_db
Usuario: root
Contrasena: gcn1b8xn

 en MySQL Workbench
1. Abra MySQL Workbench
2. Cargue y ejecute el archivo schema.sql 

version de Python
1. ejecute en su terminal:
   bash
   pip install mysql-connector-python
   
2. Inicie la aplicacion desde la carpeta del proyecto con el comando:
   bash
   python parcial_python.py
   
version de Java
1. Abrir NetBeans.
2. Importe el proyecto Parcial_Java.
3. Permita que Maven descargue el driver de conexion especificado en el archivo pom.xml.
4. Ejecute el archivo principal`Parcial_Java.java para iniciar el menú.
